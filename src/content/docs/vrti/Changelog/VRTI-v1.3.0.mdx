## v1.3.0

### Added

- Support for the KingSmith WalkingPad Z1E
- Support for certain ESlinker-type treadmills
- Belt speed simulation for FTMS treadmills that don't report a belt speed
- Discord Rich Presence
- Dutch language support
- Japanese language support
- Translation tools for exporting bundled translations and loading custom translations

### Changed

- Improved the settings interface and treadmill setup flow
- Improved Bluetooth diagnostics with detailed discovery reports
- Renamed the KingSmith G15 driver to KingSmith Type C to reflect broader device support

### Removed

- Removed the incomplete experimental Superun FFFF driver

### Fixed

- Improved FTMS connection and reconnection reliability
- Improved Bluetooth device lookup reliability
